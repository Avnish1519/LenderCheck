# LenderCheck
iOS app to verify lender/loan-app legitimacy before sharing money or documents.
Built with SwiftUI. Track 2 — Fraud Detection & Financial Crime Prevention.

## Run
Open in Xcode 15+, select an iOS 17 simulator, hit Run.

## Current scope (prototype)
- Search a lender name against a local verified registry
- Instant Verified / Unverified trust verdict with reasoning
- Red-flag warning for unverified results

## Next
Camera-based OCR scan (Vision framework), live RBI/NBFC API integration.
